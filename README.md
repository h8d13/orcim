# orcim

```shell
mkdir -p ~/.config/micro/ && git clone https://github.com/h8d13/orcim/ ~/.config/micro/
```

You can set the editor globally (useful for `git`):

```shell
echo 'EDITOR=micro' | sudo tee /etc/environment
```

Dep: `glow` and `lua`

For `hlchunk` modes needs https://github.com/h8d13/micro built.
